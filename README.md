# NameMatch Excel

A mobile-friendly browser app that compares the name columns in two Excel or CSV files and downloads a new Excel report containing matching records.

## Features

- Upload `.xlsx`, `.xls`, or `.csv` files
- Automatically suggests the likely name column
- Ignores capitalization, punctuation, extra spaces, and optionally name order
- Preserves source columns from both files
- Creates a downloadable workbook with **Matching Names** and **Summary** sheets
- Processes files locally in the browser

Open `index.html` or publish the repository with GitHub Pages.
